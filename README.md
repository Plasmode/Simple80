# Simple80
A simple Z80 SBC.  There are two versions of Simple80:
- [Rev0.x](Rev0) has no glue logic, just Z80/SIO/RAM/ROM.  It needs a simple CF disk board to run CP/M.
- [Rev1.x](Rev1) incorporated the simple CF logic on board, so no additional boards are needed to run CP/M.
